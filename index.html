How to use this

Type a Right Ascension and Declination (decimal degrees, or hours/degrees like 08h55m10.8s and -7d14m42.5s), or an object name, then press Make flipbook. Examples are one click away. The tool asks NASA's archive (IRSA) for every SPHEREx exposure covering that spot, cuts out a small square from each, lines them up on the sky, subtracts the background and plays them like a short video.

Stars that stay put stay put. A nearby star, brown dwarf, comet or asteroid shifts between frames. A variable star changes brightness, shown in the small chart under the picture. "One stacked image per epoch" adds up the exposures from each visit for a cleaner picture. "Epoch minus first epoch" shows only what changed since the first visit: bright and dark spots mean something moved or varied.

Share a view by copying the link. You can also build one yourself: add ?ra=269.452&dec=4.693&fov=0.1&det=SPHEREx-D6&mode=single to the page address.

"Epoch minus previous epoch" is handy for fast movers: it shows what changed between each visit and the one before. A bigger field of view (type any size from 0.02 to 0.6 degrees) can catch faster movers but takes longer to download. Dark blue pixels mean the exposure has no data there. Under each exposure you see how much of the field has no data and how many pixels carry a quality flag (flags are shown, not removed; see the SPHEREx documentation for what each flag bit means).

Limits: the NASA archive is sometimes slow or busy, so a request can take a minute or fail, and it may need another try. Each SPHEREx exposure covers only one band per detector, so frames from one detector differ slightly in color. Not built yet: Gaia and WISE overlays and on-the-fly spectra. New SPHEREx data shows up on its own, because the tool asks the archive directly each time.
